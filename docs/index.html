Grab any product into
builder-ready docs.

One command turns a public website, app or tutorial into a captioned PRD, design tokens, parity checklist, build roadmap and handoff zip — and stops first if the site opts out of AI.

Install the skillView on GitHub

What you get

📄 Offline PRD

One HTML file with inline SVG and base64 shots, plus md and PDF. Every figure captioned with screen, path, markers, FR ids, source.

🧭 Inventory + parity

Every feature with an FR id, and a checklist that defines what “100%” means.

🗺️ REF-ROADMAP

Numbered build steps mapped to sprints, with gap cards against your own product.

🎨 Design tokens

Colours, type, spacing, radii, motion timings measured from the real UI.

🛑 AI-access gate

robots.txt, Content-Signal, X-Robots-Tag noai, ai.txt and ToS checked before anything else.

🔁 Learns

Each run adds recipes to LESSONS.md so the next grab is faster.

How it works

1 Gate

Check AI opt-outs; stop if disallowed.

2–4 Research, Capture, Analyse

Docs, pricing, tutorials, reviews; every screen and animation; REA on legit downloads.

5–7 Inventory, PRD, Roadmap

FR ids, parity checklist, captioned PRD, build order.

8–9 Package, Learn

HANDOFF.md + ≤25 MB zips; lessons appended.

Install

cp -r grab ~/.claude/skills/
mkdir -p .cursor/skills && cp -r grab .cursor/skills/
cp -r grab ~/.codex/skills/   # or reference grab/SKILL.md in AGENTS.md
# paste grab/SKILL.md into your agent's instructions, keep grab/templates/ beside it

Then: /grab https://example.com

Clean-room

FAQ

Is this a scraper?

No. It is a research workflow for agents that documents public products for original builds, with a hard stop on AI opt-outs.

Which agents does it work with?

Claude Code, Cursor, Codex/OpenClaw, or any agent that can read a SKILL.md and run a shell.

Does it need REA?

Optional. REA adds static analysis of downloadable bundles.

Can I protect my own site?

Yes — see yravgAntiGrab.
